# 缓存、CRC 与紧凑页/VA 优化结果

2026-11-10；测量源码46c92cb156b5f4f9c96ff88dd2a87165761f5f6a。全部D盘，无推送、提测、初赛分支或全局设置改动。对照为同一新二进制内旧字节CRC+零缓存，并非历史二进制比较。详见[方法](portfolio-method.md)和bench/results原始JSONL。

## 生产核心

默认格式兼容IEEE CRC32 slicing-by-8；新增完整验证后准入、每个Store独立的有界INDEX页缓存。命中仍核对层级/类型。不缓存根槽或溢出数据页，不改变格式02、提交同步、保存点和恢复语义。根据实测SQL默认缓存1MiB，可用Options.index_cache_bytes=0关闭；底层Store默认0。条目数组实际1,048,560字节，固定对象/分配器额外计。

2,000行/128维/40查询，三轮中位数：

| 模式 | 写入ms | 查询ms |
|---|---:|---:|
| bytewise-cache0 | 546.548 | 728.692 |
| bytewise-cache1048576 | 271.018 | 668.207 |
| bytewise-cache262144 | 271.323 | 702.607 |
| slicing8-cache0 | 334.714 | 263.385 |
| slicing8-cache1048576 | 260.462 | 248.096 |
| slicing8-cache262144 | 261.350 | 273.668 |

组合写入减少52.34%，查询减少65.95%。保留负面结果：256KiB+slicing查询中位数高于无缓存，小差异不泛化。各组文件和结果一致，文件10,223,616字节；本轮没有降低写放大或文件大小。

10,000行/128维/1,000查询，三轮中位数：

| 模式 | 写入ms | 查询ms | 峰值RSS中位KiB |
|---|---:|---:|---:|
| bytewise-cache0 | 2770.212 | 85424.917 | 18884 |
| slicing8-cache1048576 | 1328.955 | 30342.877 | 20056 |

写入减少52.03%，查询减少64.48%（约2.82倍）。6,000查询和6重启全行核对通过。内存含驱动和参考结果，不是引擎单独内存；热OS缓存不代表冷盘、物理SSD或官方得分。

独立诊断：写入pread32,005→514，CRC次数34,485→2,994。仅换CRC不减少读取，写入CRC230.406→53.959ms，查询CRC576.654→127.953ms；组合后4.712和112.363ms。小规模1MiB缓存写入命中31,491，查询命中7,960且无未命中；大规模查询命中231,000且无未命中。查询仍读取全部数据页，缓存不能替代紧凑布局。

## 独立研究原型，未接入SQL/事务

受[PAX](https://www.pdl.cmu.edu/ftp/Database/pax.pdf)页内组织与[VA-file](https://www.vldb.org/conf/1998/p194.pdf)保守摘要过滤启发，实验一页七行、4-bit/维区间摘要和严格下界精确剪枝。这不是完整PAX列布局，也不以ANN召回替代精确正确性。12字节payload不同于生产256字节，禁止叠乘两组加速比。无SQL、事务、恢复、更新或格式迁移。

10,000行、200查询，三轮中位数：

| 数据 | 模式 | 查询ms | 读页 | 精确距离 | 文件字节 |
|---|---|---:|---:|---:|---:|
| uniform | one_row | 8709.650 | 2000200 | 1125000 | 40964096 |
| uniform | packed | 4682.250 | 286000 | 1125000 | 5857280 |
| uniform | packed_va | 3095.990 | 119990 | 107599 | 6615040 |
| clustered | one_row | 8641.130 | 2000200 | 1125000 | 40964096 |
| clustered | packed | 4672.360 | 286000 | 1125000 | 5857280 |
| clustered | packed_va | 2826.380 | 287325 | 252825 | 6615040 |

紧凑页相对一行一页约快1.85倍；VA相对紧凑页，均匀数据再减少33.88%耗时，聚类减少39.51%。文件40,964,096→5,857,280字节，增加VA后6,615,040字节。聚类VA读页287,325高于纯紧凑286,000：摘要有额外成本，候选分散，耗时下降不能全部归因IO。组标签与簇相关且过滤查询匹配自身簇，属于有利条件，不能泛化。

较小2,000行/40查询也保留，聚类VA读页11,745高于紧凑11,480。两规模共4,320次原型查询ID与未格式化binary64距离等于独立全排序参考。下界逐步保守向下舍入，严格bound>第k距离才剪枝并保留并列次序；禁止fast-math并使用-ffp-contract=off。只校验请求页，不扫描被跳过页的损坏。

查询状态有界，但离线生成/真值持有数据，驱动保留查询/答案；不是生产外存构建保证。查询计时含开关文件与结果比较，构建耗时是所有格式合计且无fsync。更多证明/限制见experiments/README.md。
