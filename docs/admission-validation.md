## 修复内容

1. Docker 默认入口改为原生 C++ JSONL。恢复完成后主动发准确 ready；解析 execute/sql/search_mode；原样回传 id 类型及大整数；查询以 columns/rows 返回，修改带 affected_rows，错误后继续服务。shutdown 回滚未提交事务、关闭数据库后应答并退出0。
2. 查询响应使用64KiB缓冲，超过后写入 /data 下立即 unlink 的临时文件，完成后才输出。磁盘写入失败不会发出半条成功 JSON，也不要求全结果常驻内存。dev-tsv 仅作为显式开发选项保留。
3. CREATE VECTOR INDEX 建立真实磁盘平坦向量索引；增删改、失败语句、显式回滚与重启都使用同一个提交根。exact/ann 均为完整精确搜索，未实现近似剪枝，不宣称性能提升。详见 [索引说明](vector-index.md)。
