MiniVectorDB实现与验证说明
作者：Agent。用于解释代码和现有实验，不作为用户历史原话或独立技术理解的替代证据。

追加日志与写放大（append-only journal / write amplification）
a24的新库使用J08追加日志：变更记录在文件尾追加，提交根记录已提交的可达位置，内存目录只保存键与记录偏移。它减少了逐批修改树路径产生的重复写入。写放大用实际设备写入量衡量，文件更小不必然意味着端到端耗时更短。

失败原子性与持久化确认（failure atomicity / durable acknowledgement）
写入语句失败后应恢复该语句之前的可见状态，保留显式事务中之前成功的语句；COMMIT确认前必须完成相应持久化。内存目录重排不允许提前发布新的记录偏移。保存点恢复、未提交进程退出、损坏检测与已提交记录重启核验是不同检查，不能互相替代。

分块连续目录与局部性（blocked sorted directory / locality）
新实验将逐键树节点改为有序连续块，每块最多512个键与偏移，块内移动有界。定位先查块，再查块内位置；顺序追加尽量填满已有块。它希望减少分配次数、指针跳转和每个键的管理开销。随机插入仍需移动块内元素，不能先验断言所有负载都更快；以原生T/M为采用依据。该实验不改变J08磁盘格式。

无损游程编码与字节并行扫描（RLE / SWAR）
新编码实验使用64位字运算一次检查多个可能的重复段起点。它不是对向量降精度：必须逐字节产生与旧编码器完全相同的结果，包括普通布局与字节平面布局的选择。边界处保留有界读取，不能跨越输入末端。零字节检测只用于快速排除不可能出现三连字节的位置；有可能命中时回到精确检查，不能跳过实际重复段。

有界缓存与摊销分配（bounded cache / amortized allocation）
缓存容量有明确上限，不能通过隐藏额外内存换取表面耗时收益。复用响应缓冲时，每次请求必须清除旧内容并关闭旧临时文件；复用列缓存时，必须满足相同表和索引身份，写操作与回滚需要正确失效。缓存建设的CPU、I/O和峰值内存属于准备成本，不能把它们当作不存在。

保守下界筛选与精确复核（conservative lower bound / exact verification）
整数辅助码只用于证明某候选不可能进入TopK。返回距离仍来自原float32数据和规定的计算顺序；无法证明排除时走精确路径。辅助筛选失败时的回退性能也是设计的一部分。当前两条新实验以a24为起点，没有继续修改这条查询算法。

字节等价与功能等价的区别
功能检查比较返回行、距离、排序和事务结果；字节检查比较相同操作序列产生的完整数据文件。新目录与新编码器分别都声称保持持久化字节不变，因此还要做a24与候选的文件逐字节对照。通过字节检查不代表已经证明掉电行为，也不代表一定获得性能收益。

对照实验与适用边界
每条新路线独立与a24比较，不用不同基线的百分比连乘预测正式E。默认BIGINT/VARCHAR之外，增加连续浮点、聚集、离群数据；比较完整写入/查询T、完整生命周期B和峰值M。微基准用于决定是否值得进入完整测量，不能充当正式性能分。未获得新正式结果之前，不宣称达到7000或Prompt40。
