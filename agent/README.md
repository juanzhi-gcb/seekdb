# MiniVectorDB 学习材料阅读说明

正式提交候选材料为本目录 `conversation.json`；仓库根目录同名文件是内容完全相同的兼容副本。两者须随最终源码和 Dockerfile 一起提交。本次作为用户授权的上传快照打包，最终SHA以Git提交记录为准；没有代为正式提测。

建议先读材料前部的项目概览和版本边界，再读四个案例：按需解码反例、指定版本性能基线、提交与响应一致性、无索引三轮迭代。案例中的 u/a/e 引用可直接定位后部原记录。完整e57–e62链已补进导航。

`conversations` 保存真实用户原话或有标记的节选；`experiments` 保存工具结果摘要及证据位置；`agent_observations` 和新增复盘归于 Agent。新增后续 Prompt 是尚未执行的模板，不是历史用户对话。没有做过 Prompt 自身的随机对照，也没有当前版本的正式 Prompt 分数。

旧结论保留，并用版本边界解释其后续修正。平方距离排序不能当作当前规则；0e954的下溢缺陷不能套用于8b7054；公开用例与隐藏正式准入必须分开。

材料说明了可复核的工作过程，但用户亲自解释取舍、机制和迁移的记录仍有限。对此不补造第一人称反思，也不由Agent代填理解证明。

[本地文件摘要](material-digest.json)只用于文件完整性核对，不是平台评价结果或平台内部“材料摘要”字段。分数范围、有效性及排名由平台判定；本地没有自评分或分数换算。

完整实验见[无索引报告](../docs/unindexed-results.md)；整理前材料保存在[原始快照](../bench/results/prompt-material-20261111/before-conversation.json)。
